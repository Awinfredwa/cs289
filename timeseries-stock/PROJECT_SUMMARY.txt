FEATURES IMPLEMENTED
================================================================================

✅ Data Processing
   • OHLCV CSV loading with validation
   • Date parsing and chronological sorting
   • Missing data detection and handling
   • Trading day continuity checks

✅ Feature Engineering (13+ features)
   • Returns: close_ret_1
   • Rolling stats: roll_mean_5/10, roll_std_5/10
   • Momentum: RSI_14
   • MACD: macd, macd_signal, macd_hist
   • Volume: vol_roll_mean_5/20, vol_zscore_5/20

✅ Time-Series Windowing
   • Configurable look-back window (default: 7 days)
   • Stride support for overlapping/non-overlapping windows
   • Proper target alignment (no leakage)
   • Shape validation

✅ Data Splitting
   • Chronological train/val/test split (70/15/15)
   • No data leakage (fit scaler on train only)
   • Standardization with StandardScaler

✅ Models
   • LSTM: Multi-layer with dropout
   • 1D-CNN: Conv layers + global pooling
   • Support for classification & regression

✅ Training Pipeline
   • Early stopping (configurable patience)
   • Model checkpointing (saves best model)
   • Learning rate optimization (Adam)
   • Batch training with DataLoader

✅ Evaluation
   • Classification: accuracy, F1, precision, recall, hit rate
   • Regression: MAE, MSE, RMSE, MAPE
   • Test set predictions saved to disk

✅ Configuration
   • YAML-based config system
   • CLI parameter overrides
   • Config snapshot saved with each run

✅ Extension Points
   • Sentiment data integration stubs
   • Multi-ticker framework
   • Modular feature pipeline

✅ Testing
   • Window construction validation
   • Feature leakage verification
   • Target alignment tests

QUICK START COMMANDS
================================================================================

# Install dependencies
pip install -r requirements.txt

# Run tests
python tests/test_windows.py
python tests/test_features.py

# Train with sample data
python -m src.train --config config/default.yaml

# Try different configurations
python -m src.train --config config/default.yaml window.size=14
python -m src.train --config config/default.yaml model.type=cnn1d
python -m src.train --config config/default.yaml train.task=regression

# Use your own data
# 1. Place CSV in data/raw/
# 2. Update config/default.yaml
# 3. Run training
